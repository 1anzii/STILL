STILL 使用指南
版本 1.9.4（build 22）｜适用于 macOS 13 及以上，支持 Apple 芯片与 Intel Mac。

安装与打开
先打开 DMG 安装包或解压 ZIP，再把 STILL.app 拖到「应用程序」后打开。点击屏幕右上方菜单栏中的 STILL 图标即可操作；应用不常驻 Dock。
升级前，先在旧版本中恢复正常休眠并退出，再替换 App。只有电源服务版本变化时才需要重新授权；本版继续使用服务 1.1.0。

开始使用
1. 拖动旋钮或点击周围刻度，在 30 MIN（30 分钟）、1 H、2 H、4 H、8 H、24 H 六档间选择；H 表示小时。
2. 将拨杆拨到 RUN（保持运行）。首次开启会出现 macOS 管理员授权窗口，用于启用电源服务；应用不会保存密码。
3. 确认指示灯变绿、状态显示保持运行后，再合盖。剩余时间显示在面板上，到期会恢复正常休眠规则。
4. 要提前结束，将拨杆拨回 SLEEP（正常休眠）。正常退出应用也会请求恢复；若出现提示，请确认恢复成功后再离开。

指示灯与设置
暗色：未开启保持运行。绿色：已确认保持运行。黄色：正在切换或需要处理，请查看旁边的文字提示。
拨杆槽呈红色表示保持运行已关闭（正常休眠），绿色表示已确认保持运行；处理中或状态未知时保持中性色。原状态灯及文字仍共同说明状态。
点击面板右上角的设置按钮，可调整以下选项：
「仅接电源时运行」默认开启，拔掉电源时会结束保持运行；关闭此项后可以使用电池，不设最低电量限制，请自行留意剩余电量。
「登录时启动」让 STILL 在登录 Mac 后自动打开，不会自动开启保持运行；如系统要求，请在「系统设置 → 通用 → 登录项」中允许。

使用前请了解
保持运行会暂停系统级休眠，也会影响闲置和主动休眠。停止后恢复的是 macOS 正常规则；连接外接显示器时，系统自身仍可能允许合盖运行。
请先在自己的机型上短时间验证。运行时保持通风，放入包内或运输前，结束保持运行并确认恢复成功。请勿同时开启其他防休眠工具。
应用会在到期、失联、使用电池但无法确认电池状态，或系统报告温度过高时尝试恢复休眠；这些保护不能代替用户确认，也不能保证所有机型与公司策略都支持合盖运行。

首次打开提示无法验证开发者
当前版本使用本地 ad-hoc 签名，未经过 Apple 公证。确认安装包来自可信同事后，先尝试打开，再到「系统设置 → 隐私与安全性 → 安全性」选择「仍要打开」。公司管理的 Mac 可能需要 IT 批准。无需关闭系统全局安全保护。

卸载
先拨到 SLEEP（正常休眠）并确认恢复成功，再关闭「登录时启动」。打开「设置 → 使用说明与关于 → 故障恢复与卸载」，点击「卸载电源服务」并完成管理员授权。卸载成功后退出 STILL，将「应用程序」中的 STILL.app 移到废纸篓。

高级：应急恢复
需要立即恢复系统休眠时，在「终端」执行：
sudo pmset -a disablesleep 0
pmset -g
确认 SleepDisabled 为 0。此命令也可能影响其他防休眠工具；若仍显示异常，请联系 IT 或重启后检查。
